# Folder Scripts

Letakkan file `boot.img` dari Qassa ROM kamu di folder ini!

File yang dibutuhkan:
- `boot.img` → wajib ada sebelum menjalankan workflow

Cara mendapatkan boot.img:
1. Dari ROM zip Qassa yang kamu download
2. Extract ROM zip → cari file boot.img
3. Atau gunakan file boot.img yang sudah kamu punya
